# 축의금 접수 데스크

결혼식장 접수 데스크에서 축의금을 기록하는 웹앱입니다.
브라우저에서 바로 열어 쓰고, **입력한 내용은 본인 컴퓨터 밖으로 나가지 않습니다.**

👉 **[바로 사용하기](https://rlaks5757.github.io/wedding-reception-desk/)**

---

## 이런 상황을 위해 만들었습니다

- 하객 줄이 밀립니다. 한 건에 5초 안에 끝나야 합니다.
- 예식장 와이파이는 믿을 수 없습니다. 인터넷이 끊겨도 접수는 계속돼야 합니다.
- 엑셀로 하면 셀을 옮겨 다니다 실수가 납니다.
- 끝나고 나면 양가에 드릴 명단이 필요합니다.

## 기능

- **키보드만으로 접수** — 이름 치고 금액 고르고 Enter. 마우스를 잡을 일이 없습니다.
- **봉투번호 자동 부여** — 실물 봉투와 번호가 어긋나지 않습니다. 기록을 지워도 번호를 재사용하지 않습니다.
- **금액 한글 표시** — `50,000` 아래에 `오만원`이 떠서 0을 하나 더 친 걸 바로 알아챕니다.
- **현금 대조** — 실제 센 금액을 넣으면 차액이 즉시 나옵니다. 양가에 "맞습니다"를 확인받는 순간에 씁니다.
- **엑셀 내려받기** — CSV로 받아 그대로 엽니다. 한글이 깨지지 않습니다.
- **여러 예식 관리** — 한 번 열어두면 다음 결혼식에도 그대로 씁니다.

## 개인정보

이 앱은 **어떤 데이터도 서버로 보내지 않습니다.** 보낼 서버가 없습니다.

- 입력한 하객 이름과 금액은 **본인 브라우저에만** 저장됩니다.
- 외부 요청이 하나도 없습니다. 광고, 분석 도구, 폰트 CDN 전부 없습니다.
- 인터넷을 끊어도 똑같이 동작합니다.

코드는 HTML 파일 하나가 전부입니다. 직접 열어서 확인하실 수 있습니다.

## 사용법

### 1. 예식 만들기

신랑·신부 이름, 날짜, 그리고 **본인이 접수하는 쪽**(신랑측 또는 신부측)을 고릅니다.
한 예식에서는 한쪽만 접수한다고 보고 만들었습니다. 접수 중에는 측이 바뀌지 않습니다.

### 2. 접수

| 키 | 동작 |
|---|---|
| `Tab` | 다음 칸으로 |
| `Enter` | 접수 확정 → 다음 하객 |
| `Esc` | 지금 입력 중인 것 취소 |

Enter를 누르면 폼이 비워지고 이름 칸으로 커서가 돌아갑니다. 계속 치기만 하면 됩니다.

식권과 답례품은 각각 `−`/`+`로 수를 맞춥니다(기본 식권 1, 답례품 0). 한 봉투에 식권과 답례품이 섞여도 됩니다.

금액 칸은 **만원 단위**로 입력합니다. `5`를 치면 5만원, `15`를 치면 15만원이 들어갑니다.
소수점도 받습니다 — `3.5`를 치면 3만 5천원입니다. 프리셋 버튼을 눌러도 되고, 직접 타이핑해도 됩니다.
1,000만원이 넘는 금액은 칸 아래에 경고가 뜨고, "확인했습니다" 버튼을 눌러야 접수됩니다
(Enter를 여러 번 눌러도 그냥 통과되지 않습니다).

### 3. 정산

총 건수·금액·식권·답례품과 금액대 분포가 나옵니다.
실제 센 현금을 넣으면 기록과의 차액이 바로 표시됩니다.
마지막에 엑셀 파일을 내려받으면 끝입니다.

## 데이터 보관

기본은 **브라우저 저장소**입니다. 창을 닫거나 컴퓨터를 꺼도 남아 있습니다.

추가로 **JSON 파일에 자동 저장**할 수 있습니다. 접수 화면에서 파일을 한 번 지정하면
이후 입력할 때마다 그 파일에 기록됩니다. 컴퓨터가 고장 나도 파일이 남습니다.

> 파일 자동저장은 Chrome과 Edge에서만 됩니다. Safari·Firefox는 브라우저 저장소만 씁니다.
> 브라우저를 껐다 켠 뒤에는 파일 저장 버튼을 한 번 눌러 다시 연결해줘야 합니다 (브라우저 보안 정책).

저장해둔 JSON 파일은 예식 목록 화면의 **"파일에서 불러오기"** 버튼으로 다시 불러올 수
있습니다. 브라우저 저장소가 지워졌거나, 다른 컴퓨터로 옮겨 작업을 이어갈 때 씁니다.
모든 브라우저(Chrome·Edge·Safari·Firefox)에서 동작합니다.

파일을 불러오기 전에 신랑·신부 이름, 날짜, 접수 건수, 총액을 먼저 보여주고 확인을
받습니다. 같은 예식이 이미 있으면 현재 건수와 파일 건수를 나란히 보여주고 덮어쓸지
물어봅니다 — 확인 없이는 아무 데이터도 바뀌지 않습니다. 형식이 깨졌거나 축의금 접수
파일이 아닌 JSON은 그 자리에서 거부되고, 기존 데이터는 그대로 남습니다.

## 직접 실행하기

파일 하나만 받으면 됩니다.

```
git clone https://github.com/rlaks5757/wedding-reception-desk.git
cd wedding-reception-desk
```

`index.html`을 브라우저로 열면 바로 씁니다.

파일 자동저장까지 쓰려면 로컬 서버로 띄워야 합니다 (브라우저 보안 정책상 `file://`에서는 막힙니다):

```
python3 -m http.server 8000
```

그리고 `http://localhost:8000` 으로 접속합니다.

## 만들어진 방식

의존성이 없습니다. 프레임워크도, 빌드도, `node_modules`도 없습니다.
HTML 파일 하나에 전부 들어 있습니다 — 그래야 예식 당일에 고장날 게 없습니다.
